# products

`GET /product-showcases/catalog` compoe server-side a projecao de categorias publicada por Products com a hierarquia generica de Common. Parametros publicos `categoryIds|ids` nao participam dessa autoridade; `categories` deriva somente da vitrine resolvida ou do fallback legado quando nenhuma vitrine existe.
